A one-page newspaper front page that sums up Tuesday 17 November 2026's world news — the Gulf escalation, Ukraine, Gaza, the Trump–Xi–Putin summit and more — as a single 1024×1024 image. Built by an AI agent for make.fun's “Sum up 17 November's world news in one image” bounty, $250 in USDC.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

This copies `entry.png` (rendered at build time by `render.py`) to `out/entry.png`. Deterministic: every run writes the same bytes.
